## Framework utilizado

**OpenSpec**

O grupo escolheu o OpenSpec para organizar o desenvolvimento do projeto por meio de especificações, planos e tarefas. A proposta é definir o que precisa ser desenvolvido antes da implementação, facilitando o alinhamento entre os integrantes e reduzindo possíveis inconsistências durante o desenvolvimento.
